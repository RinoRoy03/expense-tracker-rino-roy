# Expense Tracker

A responsive expense tracker built with HTML, CSS, and JavaScript.

## Features

* Add income and expense transactions
* Edit and delete transactions
* View total income, expenses, and current balance
* Category-wise expense chart
* Filter transactions by type and category
* Persist data using browser Local Storage
* Input validation and helpful error messages
* Responsive layout for desktop and mobile

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add transactions using the form.

No build tools or external dependencies are required.

## Data storage

Transactions are stored in the browser's Local Storage under the key `rinoExpenseTrackerTransactions`.

## Technologies

* HTML5
* CSS3 (Flexbox)
* JavaScript (ES6+)
* Local Storage API
